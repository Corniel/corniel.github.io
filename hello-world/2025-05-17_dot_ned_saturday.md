# dot Ned { Saturday }
## Static Code Analysis

It was nice to be back a third time at [dot Ned { Saturday }](https://dotnedsaturday.nl).
It turned out to be the last time too, as the dot Ned organization decided
that their mission - providing (Dutch) information about .NET - has been
completed, 25 years after they started. I personally really liked the dot Net
{ Saturday } set up...

This time I took the opportunity to talk about the [.NET project file analyzers](https://dotnet-project-file-analyzers.github.io)
project (co-written with Wesley Baartman, with support of others). It was
the first time I gave a talk about this project, which is always a challenge;
will the story telling work out, will it fit in the hour given, will the
audience like it?

I was content with how things worked out, and hope that it will help [.NET project file analyzers](https://dotnet-project-file-analyzers.github.io)
to get some traction, as I strongly believe that the project deserves it.
Thanks to all who contributed to this open source initiative.
